# صفحه‌ساز شخصی (فیوچریستیک)

ساخت و ویرایش یک صفحه‌ی شخصی با امکان افزودن لینک و تغییر ظاهر.

## اجرا
فایل `index.html` را با مرورگر باز کنید. نیازی به نصب یا سرور نیست.

## ساختار پروژه
- `index.html` : ساختار صفحه و پنل ویرایش
- `style.css`  : ظاهر، تم نئونی و انیمیشن‌ها
- `script.js`  : منطق برنامه (ویرایش، لینک‌ها، تم‌ها، ذخیره‌سازی، افکت‌ها)

## امکانات
- ویرایش نام، متن درباره من، آواتار (ایموجی یا عکس)
- افزودن، ویرایش، حذف و جابه‌جایی لینک‌ها
- ۵ تم آماده، تغییر رنگ‌ها، فونت و شکل دکمه‌ها
- انیمیشن‌ها (قابل خاموش‌شدن)
- ذخیره‌ی خودکار در localStorage، خروجی و ورودی JSON
